# Cheat-ShellShock-Live

## Управление:

- **Клавиша "1"** – Устанавливает начальную точку (позиция танка).
- **Клавиша "2"** – Устанавливает целевую точку (позиция врага).
- **Клавиша "3"** – Включает/выключает зеркальный режим.
- **Клавиша "4"** – Сбрасывает все позиции.
- **Клавиша "5"** – Переключает режим расчёта между углом и скоростью.

---

## Controls:

- **Key "1"** - Sets the starting point (tank position).
- **Key "2"** - Sets the target point (enemy position).
- **Key "3"** - Enables/disables mirror mode.
- **Key "4"** - Resets all positions.
- **Key "5"** - Switches the calculation mode between angle and speed.
